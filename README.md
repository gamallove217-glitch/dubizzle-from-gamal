# رادار عقارات القاهرة الجديدة — ملاك مباشرة

سكريبر بيجري كل ساعة على GitHub Actions، بيدوّر على إعلانات العقارات في القاهرة الجديدة
من **المالك مباشرة** (مش سمسار)، وبينشرها على صفحة ويب ثابتة + بوت تليجرام.

## المصادر

| المصدر | الملف | ملاحظات |
|---|---|---|
| dubizzle.com.eg | `scraper.py` | المصدر الأساسي — فيه «بوكس البائع» اللي بيقول عدد الإعلانات النشطة |
| aqarmap.com.eg | `extra_radar.py` | |
| eg.opensooq.com | `extra_radar.py` | |

## الملفات

| الملف | الوظيفة |
|---|---|
| `scraper.py` | اكتشاف إعلانات دوبيزل + فحصها + تصنيفها + الحفظ في `ads.json` |
| `extra_radar.py` | عقارماب والسوق المفتوح + إرسال تليجرام |
| `ads.json` | قاعدة البيانات (إعلانات + IDs مفحوصة + حسابات ممنوعة) |
| `index.html` | واجهة العرض (صفحة ثابتة على GitHub Pages) |
| `.github/workflows/scrape.yml` | الجدولة الساعية |

## التشغيل محلياً

```bash
pip install -r requirements.txt
python -u scraper.py
python -u extra_radar.py
```

## متغيرات البيئة

كلها اختيارية — لو مش موجودة البرنامج بيشتغل بالقيم الافتراضية.

| المتغير | الافتراضي | الوظيفة |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | *(فاضي ⇒ تليجرام متعطّل)* | توكن البوت. **لازم يبقى Secret مش في الكود** |
| `NTFY_BAN_TOPIC` | اسم قديم مكشوف | موضوع ntfy للبانات المحظورة |
| `MAX_RUNTIME_SECONDS` | `480` | ميزانية زمن السكريبر |
| `DISCOVERY_BUDGET_SECONDS` | `240` | ميزانية زمن مرحلة الاكتشاف لوحدها |
| `MAX_AD_AGE_DAYS` | `12` | أقصى عمر إعلان يُقبل |
| `AQARMAP_MIN_ID` | `7150000` | حد أدنى لـ ID عقارماب يُعتبر «حديث» |
| `OPENSOOQ_MIN_ID` | `289000000` | حد أدنى لـ ID السوق المفتوح يُعتبر «حديث» |

> ⚠️ **`AQARMAP_MIN_ID` و`OPENSOOQ_MIN_ID` أرقام بتكبر مع الوقت.**
> لما تلاحظ إن المصدر بقى ما بيضيفش حاجة، ارفع الرقمين من إعدادات الـ workflow
> (Variables) — مش محتاج تعدّل الكود.

## إعداد الأسرار على GitHub

`Settings → Secrets and variables → Actions → Secrets` وضيف:

- `TELEGRAM_BOT_TOKEN` — من [@BotFather](https://t.me/BotFather)
- `NTFY_BAN_TOPIC` — اسم عشوائي طويل (مثلاً UUID)

## ملاحظات أمنية مهمة

- **أي قيمة مكتوبة في `index.html` هي قيمة علنية.** كلمة سر الـ«VIP» وموضوعات ntfy
  في صفحة HTML ثابتة = أي زائر يقدر يقراهم من الـ source. الحماية الحقيقية محتاجة
  خادم صغير (مثلاً Cloudflare Worker) يتحقق من سرّ.
- **توكن تليجرام كان مكتوب في الكود** (`extra_radar.py`) واتنقل لمتغير بيئة.
  لو التوكن القديم لسه شغال، **الغِه فوراً** من BotFather واعمل واحد جديد.
- بيانات الإعلانات (العنوان/الوصف/اسم البائع) بتتعرّب بـ `esc()` قبل ما تتحط في
  الصفحة — عشان أي إعلان خبيث ما يشغّلش كود في متصفح الزوار.

## بنية `ads.json`

```
ads[]                  قائمة الإعلانات
checked_ids_v11        {id: {t: تاريخ, r: سبب}} — ذاكرة المفحوص (بتنتهي بعد 14 يوم)
nocnt_attempts_v1      {id: عدد المحاولات} — عشان ما ندخلش في لوب لا نهائي
banned_accounts_v7     حسابات السماسرة الممنوعة
last_run_report        ملخص آخر رَن (العداد اللي بيتعرض في الصفحة)
telegram_last_update_id  آخر رسالة اتعالجت في البوت
```
